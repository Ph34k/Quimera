## 2024-05-27 - Fix SSRF Vulnerability in Quimera Agents
**Vulnerability:** Server-Side Request Forgery (SSRF) in `IExecutionAgent` and `IScoutAgent` allowing attackers to make arbitrary HTTP requests to internal networks and cloud metadata services.
**Learning:** Using an `httpx` event hook (`event_hooks={'request': [hook]}`) is an effective way to apply validation logic across initial requests and all subsequent redirects. Additionally, when using `ipaddress` to validate safe IPs, checking `not ip.is_global` is more comprehensive than listing exclusions (e.g., `is_private`, `is_loopback`), as it inherently blocks link-local addresses (like `169.254.169.254` AWS metadata). Note that while this method blocks direct access, it does not fully prevent DNS rebinding (TOCTOU) without a custom transport, though it represents an industry-standard baseline defense.
**Prevention:** Always validate user-supplied URLs to ensure they resolve to globally routable IP addresses before dispatching requests via backend HTTP clients, and ensure redirection chains are also validated.
