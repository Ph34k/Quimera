## 2024-05-15 - SSRF Vulnerability in Web Scraping Agents
**Vulnerability:** `IScoutAgent` and `IExecutionAgent` previously used `httpx.get()` globally without validating the `target_url`, allowing Server-Side Request Forgery (SSRF). Attackers could potentially force the server to issue requests to internal networks or loopback addresses.
**Learning:** In agent architectures that rely on fetching user-provided URLs for OSINT or web driving, implicit trust in `target_url` is a critical security gap. Furthermore, using a persistent `httpx.Client` per agent without a `__del__` method can lead to resource leaks in asynchronous environments.
**Prevention:** Always validate external URLs using socket resolution to block private/local IP ranges (`socket.getaddrinfo`) prior to making HTTP requests. Use `httpx.Client` event hooks (`verify_request`) to enforce this check universally, including during redirects. Implement explicit cleanup methods (`__del__`) for persistent clients.
