## 2024-05-18 - SSRF Vulnerability in HTTP Agents
**Vulnerability:** IScoutAgent and IExecutionAgent were directly using `httpx.get()` with user-supplied URLs without validation. This allowed an attacker to input URLs pointing to internal or private IP addresses, leading to a Server-Side Request Forgery (SSRF) vulnerability.
**Learning:** Directly using user-supplied URLs for HTTP requests bypasses the network perimeter. The application must perform DNS resolution and check the resulting IP address against a list of blocked/private address spaces before initiating the request. Relying only on URL string parsing is insufficient due to IP formats and DNS rebinding (TOCTOU).
**Prevention:** Implement a rigorous `is_safe_url` check that uses `socket.getaddrinfo` to resolve the hostname and verifies that none of the resolved IPs belong to private, loopback, link-local, multicast, or unspecified ranges. Utilize `httpx` event hooks (`verify_request`) to intercept and validate requests before they are executed.
