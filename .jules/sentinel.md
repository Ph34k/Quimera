## 2026-05-27 - Elasticsearch Security
**Vulnerability:** Disabled Elasticsearch security (xpack.security.enabled=false).
**Learning:** Elasticsearch should have security enabled to prevent unauthorized access to data.
**Prevention:** Always set xpack.security.enabled=true and configure credentials.

## 2024-06-14 - Prevent SSRF with redirect validation
**Vulnerability:** IScoutAgent and IExecutionAgent were vulnerable to Server-Side Request Forgery (SSRF) because they used httpx.get() directly without validating if the target resolved to internal IP addresses (e.g., localhost, private subnets).
**Learning:** Simply checking the initial URL is insufficient if the HTTP client automatically follows redirects to a malicious internal IP.
**Prevention:** Use httpx event hooks (`event_hooks={'request': [...]}`) to validate the resolved IP address of every URL requested, including those generated by redirects, blocking loopback, private, link-local, and unspecified IPs.
